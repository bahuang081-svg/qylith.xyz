The thesis

The next chain should not inherit yesterday's cryptographic assumptions.

Most networks treat post-quantum security as a later migration. Qylith treats it as the base constraint: every signature, proof, and runtime decision is designed around adversaries that do not stay classical.

01 / Native defense

Quantum-resistant from launch

Consensus and account security are built on post-quantum primitives instead of bolted onto classical keys later.

02 / Verifiable scale

STARK-based execution

Transparent proofs keep verification lightweight without requiring trusted setup ceremonies.

03 / Agent layer

AI as protocol surface

Autonomous contracts and agent workflows become first-class network behavior, not an off-chain afterthought.
